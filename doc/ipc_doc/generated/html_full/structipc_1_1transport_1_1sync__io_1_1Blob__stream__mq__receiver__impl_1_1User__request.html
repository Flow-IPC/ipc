Detailed Description

template<typename Persistent_mq_handle>
struct ipc::transport::sync_io::Blob_stream_mq_receiver_impl< Persistent_mq_handle >::User_request

Identical to sync_io::Async_adapter_receiver::User_request_one, except we only keep at most 1 of these and thus don't need a Ptr alias inside; and we need not worry about transmitting Native_handles.

As in that other class, this records the args from an async_receive_blob() call.

Note
If you're wondering why there is no batch-receive equivalent of this, the reason is that we use the async_receive_batch_emulation() pattern so as to build async_receive_blob_batch() as a series of async_receive_blob_impl(). So User_request is again used.
