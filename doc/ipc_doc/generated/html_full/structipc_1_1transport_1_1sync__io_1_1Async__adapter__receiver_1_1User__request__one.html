Detailed Description

template<typename Core_t>
struct ipc::transport::sync_io::Async_adapter_receiver< Core_t >::User_request_one

Data store representing a deficit user single-message async-receive request: either one being currently handled by m_sync_io – which can handle one m_sync_io.async_receive_*() at a time, no more – or one queued up behind it, if async_receive_*() was called before the current one could complete.

Essentially this stores args to async_receive_native_handle() (or degenerate version, async_receive_blob()) which is an async-operating method. We store them in queue via User_req_ptr.
