Detailed Description

template<typename Shm_lender_borrower_t, typename Shm_arena_t>
struct ipc::transport::struc::shm::rpc::Session_vat_network< Shm_lender_borrower_t, Shm_arena_t >::Fulfiller_disposer

Disposer for Own<Rpc_conn> returned by connect() and accept() which (1) does not delete anything and (2) fulfills m_disconnect_promise once all such Owns have dropped their Rpc_conns.

Why? Answer: See m_disconnect_promise doc header. It isn't really central to Session_vat_network, so don't worry about it, unless you really have to.
