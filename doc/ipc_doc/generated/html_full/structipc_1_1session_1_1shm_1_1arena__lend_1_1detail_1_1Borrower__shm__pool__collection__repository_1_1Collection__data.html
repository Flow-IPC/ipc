template<typename Shm_arena_t>
struct ipc::session::shm::arena_lend::detail::Borrower_shm_pool_collection_repository< Shm_arena_t >::Collection_data

Ref-counted collection data.

Multiple Shm_sessions to the same owner-ID + collection-ID each register the same collection; m_use_count tracks how many; the Borrower_shm_pool_collection is shared among them.
