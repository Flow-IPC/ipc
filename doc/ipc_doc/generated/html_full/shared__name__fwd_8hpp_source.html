278/**
279 * Utility that invokes `Persistent_object::for_each_persistent()` and synchronously invokes
280 * `Persistent_object::remove_persistent()` on each resulting item that passes the given filter,
281 * where `Persistent_object` is a type that handles objects -- such as SHM pools or POSIX MQs -- with kernel-persistent
282 * semantics.
283 *
284 * The number of items removed (without any error) is returned.
285 * The nature of any error(s) encountered by individual `remove_persistent()` calls is ignored (not returned
286 * in any way) except for logging.
287 *
288 * This "forgiving" error emission behavior is sufficient in many cases. If you require finer control over
289 * this please use `Persistent_object::for_each_persistent()` and `Persistent_object::remove_persistent()`
290 * plus your own handling of the failure thereof in your custom `handle_name_func()`.
291 *
292 * If `filter_func()` throws, this function does not go through any remaining entries; the exception
293 * is not caught.
294 *
295 * @tparam Persistent_object
296 * See above. It must have `static` methods `for_each_persistent()` and `remove_persistent()`
297 * with semantics identical to, e.g., shm::classic::Pool_arena versions of these methods.
298 * As of this writing this includes: shm::classic::Pool_arena, transport::Persistent_mq_handle (concept),
299 * transport::Posix_mq_handle, transport::Bipc_mq_handle (its impls).
300 * @tparam Filter_func
301 * Function object with signature `bool F(const Shared_name&)`, which should return `true` to delete,
302 * `false` to skip. For example it might simply check that `name` starts with a certain prefix
303 * (remove_each_persistent_with_name_prefix() uses this), or it might check whether the creating process --
304 * whose PID might be encoded in `name` by some convention (e.g., see ipc::session) -- is alive
305 * (util::process_running()).
306 * @param logger_ptr
307 * Logger to use for subsequently logging.
308 * @param filter_func
309 * See `Filter_func` above.
310 * @return The number of successful `Persistent_object::remove_persistent()` calls invoked (might be zero).
311 */
312template<typename Persistent_object, typename Filter_func>
313unsigned int remove_each_persistent_if(flow::log::Logger* logger_ptr, const Filter_func& filter_func);
