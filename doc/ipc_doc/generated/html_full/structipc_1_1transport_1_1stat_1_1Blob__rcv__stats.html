Detailed Description

Cumulative stats from the incoming-direction (receive) pipe of a Blob_receiver or Native_handle_receiver concept implementation.

Applicable to any such implementation; also counts native-handle receives if applicable.

ipc::transport::stat::Blob_rcv_stats::Blob_rcv_stats ( size_t  max_payload_size)
explicit

Constructs stats with all counters zeroed and a payload-size histogram sized for the given max payload.

The last bucket isolates exactly max_payload_size. If max_payload_size is not divisible by S_PAYLOAD_SZ_HISTO_BUCKET_SZ, bucket 0 absorbs the remainder so that subsequent bucket boundaries align and one falls exactly on max_payload_size.

Parameters
max_payload_sizeMaximum blob payload size for this transport (e.g., Native_socket_stream_cfg::S_MAX_META_BLOB_LENGTH). Must be >= 1.
