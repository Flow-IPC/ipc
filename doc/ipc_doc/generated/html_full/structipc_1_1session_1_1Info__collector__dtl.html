Detailed Description

This is the friend facade of Info_collector that exposes the private constructor, so that only internal session code (Client_session_impl, Server_session_impl) can construct a Info_collector.

The user receives a pointer to an already-constructed Info_collector via Session::info_collector() but cannot construct one themselves.
