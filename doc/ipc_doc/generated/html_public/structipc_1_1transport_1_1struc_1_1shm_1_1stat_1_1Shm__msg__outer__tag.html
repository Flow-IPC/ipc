template<typename Arena>
struct ipc::transport::struc::shm::stat::Shm_msg_outer_tag< Arena >

Empty type template: distinguishing tag for the SHM-msg-outer (heap-side envelope) flow::util::stat::Global_stats<> singleton, parameterized by the SHM-Arena type so each Arena has its own singleton.

Reach the singleton via Outer_serializer_global_stats.

For the SHM-msg-inner (SHM-resident user payload), Arena itself is used as the tag – there is no separate tag. Reach that singleton via Core_serializer_global_stats.
