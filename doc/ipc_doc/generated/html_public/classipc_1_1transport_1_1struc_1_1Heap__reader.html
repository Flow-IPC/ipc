Detailed Description

Implements Struct_reader concept by straightforwardly interpreting a serialization by Heap_fixed_builder or any other builder that produces segments directly readable via SegmentArrayMessageReader.

While written originally specifically as the counterpart to Heap_fixed_builder, it would work with any builder that produces an equivalent serialization modulo using potentially different segment sizes. That is why it is called Heap_reader – not Heap_fixed_reader or some-such.

See also
Heap_fixed_builder A counterpart Struct_builder implementation that can create compatible serializations.
