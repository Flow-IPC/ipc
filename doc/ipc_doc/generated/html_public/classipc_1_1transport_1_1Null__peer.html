Detailed Description

Dummy type for use as a template param to Channel when either the blobs pipe or handles pipe is disabled; as well as to mark a given peer object as not having a counterpart form: a sync_io object shall have its using Sync_io_obj = Null_peer and conversely for async-I/O guys and their Async_io_objs.

No object of this type is ever touched, at least if Channel is properly used.
