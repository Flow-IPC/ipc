Detailed Description

template<typename T>
class ipc::shm::arena_lend::jemalloc::Memory_manager::Extent_hooks_wrapper< T >

Wrapper around extent hooks, which are callbacks that can be instituted in jemalloc per arena.

The prescribed usage is to implement desired callbacks that execute the implementation within the creating object (arg owner to ctor). The extent_hooks* callback parameter can be cast to a pointer of this type to retrieve the owner of the callback for execution in that class object's context.

So to jemalloc, which is provided this as cast to extent_hooks_t*: It sees a table of free/static functions of yours and calls the appropriate one depending on the event (e.g.: new extent needed). (Next to that is stored the value owner given to ctor, but jemalloc does not know or care.) Each of those functions is given the extent_hooks_t* plus the hook-specific args; so the function can then

  1. take extent_hooks_t* and cast it to Extent_hooks_wrapper<T>*;
  2. call ->get_owner() on that which gets the aforementioned stored T*;
  3. on that, call the appropriate method (e.g., one that handles "new extent needed") of T, passing it the rest of the args following the extent_hooks_t* arg.
